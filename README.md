# Tulip Restaurant website

A GitHub Pages-ready responsive website for Tulip Restaurant, built from the supplied HyperFrames promo design.

## Publish on GitHub Pages

1. Upload the contents of this folder to your GitHub repository.
2. Make sure `index.html` is in the repository root.
3. In **Settings → Pages**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. Leave **Custom domain** empty unless you own a domain.
5. Wait for GitHub Pages to deploy.
